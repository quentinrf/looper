# Looper is public and generic

Looper is a public repository that encodes a way of working which is applied to private, work-owned codebases. It contains no employer names, service names, account IDs, internal URLs or other work-specific detail; anything of that kind lives in the consumer repo or a private overlay. A leak counts as a bug. We considered making looper private, but kept it public so the harness stays reusable and its boundaries stay honest.
